마상소프트 서버팀에서 게임 서버 프로그래머로 근무하며, 5개 라이브 서비스의 게임 서버 콘텐츠 개발·운영·장애 대응을 담당했습니다. 이 중 마이크로볼츠의 라이브 서비스 주 담당자로서 운영 문의 대응과 장애 처리를 맡았으며, 게임 서버 개발부터 MySQL DB 설계·운영, Linux 환경의 서버 운영까지 담당했습니다.

[담당 직무]

- 라이브 서비스 운영 및 장애 대응
다수의 라이브 서비스를 모니터링하며 장애 원인 분석 및 처리 로직 개선 업무를 수행했습니다. 대표적으로 일 평균 약 12만 건에 달하던 에러 로그 누락 문제를 분석하고 처리 구조를 개선하여, 1년이 지난 현재까지 동일 유형의 재발 없이 안정적인 운영을 유지하고 있습니다.

- 게임 콘텐츠 서버 기능 설계 및 구현
출석판 시스템을 기획 데이터 기반 구조로 재설계하여 신규 출석판 추가 시 서버 코드 수정 범위를 최소화했습니다. 또한 무기 튜닝 데이터 구조를 개선하여 기존 튜닝 데이터를 여러 무기에서 재사용할 수 있는 구조로 전환했습니다.

- 마상 크리에이터즈 지원 DLL 개발
사내 크리에이터 지원 시스템의 DLL을 구현하여 건즈 글로벌과 DK온라인에 적용했습니다. 두 게임의 서비스 구조 차이에 따라 각각 다른 결제 처리 방식(Steamworks API / 국내 빌링사 API)을 적용했습니다.

- 킹스레이드 소탕 시스템 개발 참여
Node.js, Docker, Redis 기반 환경에서 기존 소탕 시스템을 지하던전·길드 레이드로 확장하는 작업을 담당했습니다.

- 스키드러쉬 콘텐츠 개발
드리프트 자국을 표현하는 스키드마크 아이템 시스템과, 특정 콘텐츠에서만 추가 보상을 획득하는 패시브 아이템 시스템을 개발했습니다.
